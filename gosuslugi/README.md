# Мониторинг заявления на Госуслугах

Опрашивает ЛК Госуслуг по заявлению и шлёт уведомление в Telegram, как только
статус меняется — в первую очередь когда ведомство ответило и открылась запись на приём.

## Подготовка

1. **Сессия.** Залогинься на gosuslugi.ru в браузере и выгрузи куки в
   `www.gosuslugi.ru_cookies.txt` (формат Netscape — расширение «Get cookies.txt» и подобные).
   Сессия живёт ~2,5 часа. За 15 минут до конца бот пришлёт напоминание обновить файл, а после истечения — сообщение о том, что мониторинг встал.
2. **Telegram.** В `.env` (формат `KEY=value`):
   ```
   TELEGRAM_TOKEN=...
   TELEGRAM_CHAT_ID=...
   TELEGRAM_CHANNEL_ID=...
   ```
   Уведомления идут в `TELEGRAM_CHAT_ID` (личный чат), при его отсутствии — в `TELEGRAM_CHANNEL_ID`.
   Для группы/канала бот должен быть в неё добавлен.
3. **Заявление.** По умолчанию `7934451200`; переопределяется `GOSUSLUGI_ORDER_ID`.

## Запуск

```sh
node --env-file=.env monitor.mjs
```

Фоном с логом:

```sh
nohup node --env-file=.env monitor.mjs > monitor.log 2>&1 &
```

## Как это работает

- Интервал опроса — случайный, 3–6 минут (в секундах).
- Источник данных — `https://www.gosuslugi.ru/api/lk/v1/orders/<id>`.
  Страница `/600102/1/booking` отдаётся только браузеру (антибот-проверка на JS),
  поэтому мониторится API того же заявления.
- Сравниваются: `orderStatusId`, `smevMessageId`, `hasActiveInviteToEqueue`,
  `checkQueue`, `updated`, история статусов, события очереди и файлы ответа.
- Последнее состояние лежит в `state.json` — перезапуск не теряет базовую точку.
- Признак «ответ получен»: `hasActiveInviteToEqueue`/`checkQueue` стали `true`,
  появились события очереди или `smevMessageId` ушёл из `WAIT_RESPONSE`.

## Файлы

| Файл | Назначение |
|---|---|
| `monitor.mjs` | цикл опроса и уведомления |
| `order-api.mjs` | запрос к API ЛК и сжатие ответа до значимых признаков |
| `cookies.mjs` | парсер cookie-файла (Netscape) и срок жизни сессии |
| `telegram.mjs` | отправка сообщений ботом |
| `state.mjs` | чтение/запись `state.json` |
| `constants.mjs` | конфигурация |
